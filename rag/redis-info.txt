Redis는 오픈 소스 인메모리 데이터 구조 저장소입니다.

Redis의 주요 용도:
- 캐싱: 빠른 데이터 접근을 위한 캐시로 사용됩니다.
- 세션 관리: 사용자 세션 정보를 저장합니다.
- 메시지 브로커: Pub/Sub 패턴을 지원합니다.
- 리더보드: 정렬된 집합을 활용한 랭킹 시스템 구현이 가능합니다.

Redis 데이터 타입:
1. String: 기본 문자열 타입
2. List: 순서가 있는 문자열 목록
3. Set: 중복되지 않는 문자열 집합
4. Hash: 필드-값 쌍의 맵
5. Sorted Set: 점수로 정렬된 집합

Redis의 장점:
- 매우 빠른 성능 (메모리 기반)
- 다양한 데이터 구조 지원
- 복제 및 지속성 기능 제공
- TTL(Time To Live) 설정 가능
